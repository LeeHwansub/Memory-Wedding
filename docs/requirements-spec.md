# 기능 요구사항 명세서

> Memory Wedding — 모바일 청첩장 + 하객 참여형 사진·영상 아카이빙 플랫폼

## 문서 정보

| 항목 | 내용 |
|------|------|
| 버전 | 1.0.0 |
| 작성일 | 2026-09-10 |
| 상태 | Draft |

## 용어 정의

| 용어 | 설명 |
|------|------|
| PRJ (Wedding Project) | 하나의 결혼식 정보 단위. 개발 프로젝트가 아님 |
| 신랑·신부 | 서비스에 가입한 일반 사용자 |
| 하객 | 별도 회원 Role 없이 초대 링크/QR로 참여하는 사용자 |
| 관리자 | 플랫폼 운영 및 전체 Wedding Project 관리 권한 보유 |

## 사용자 구분

| 구분 | Role | 설명 |
|------|------|------|
| 신랑·신부 | USER | Wedding Project 생성·관리, 청첩장 편집, AI 결과 확인 |
| 하객 | GUEST (비회원) | 사진·영상 업로드, 방명록 작성 (초대 링크 기반) |
| 관리자 | ADMIN | 전체 회원·Project·서비스 모니터링 및 관리 |

## MVP 범위

### MVP 포함

- Google / Naver OAuth 로그인
- Wedding Project CRUD
- 모바일 청첩장 (기본 편집·조회)
- 하객 초대 링크 / QR
- 하객 사진·영상 업로드
- Google Drive 연동 (원본 저장)
- 방명록
- 관리자 기본 기능 (회원·Project 조회)

### MVP 이후

- Gemini AI 장면 분류 / Best Shot
- FFmpeg 하이라이트 영상 생성
- 청첩장 템플릿
- 방명록 수정
- Drive 용량 대시보드
- 서비스 통계
