1. **풀블리드 히어로** — 브랜드명 + 헤드라인 + CTA 2개 (만들기 / 초대 참여)

3. **쇼케이스** — 폰 프레임 미리보기 + 기능 요약
4. **How it works** — 3단계
5. **마감 CTA** + 푸터
