# 대시보드 셸 (Header · 타일 · 미리보기 모달)

> 브랜치: `feat/dashboard-shell`

## 구성

- **대시보드 Header** (`AppHeader`): 브랜드 · 로그아웃
- **프로젝트 Header** (`ProjectShell`): 프로젝트명 · 핵심 메뉴(반응형) · 미리보기
- **프로젝트 홈 타일**: 정사각 + 아이콘 + 이름
- **미리보기 모달**: 기기 프리셋 / 직접 입력 / 확대 · iframe `?embed=1`

## 모바일

프로젝트 메뉴는 `lg` 미만에서 **메뉴** 버튼 → 그리드 드로어.
